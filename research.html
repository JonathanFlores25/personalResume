Deep Dive: TransLowNet Results

Low-Light Efficiency

Using X3D as backbone, we achieved a 15% reduction in false positives in nighttime scenarios compared to traditional models, making TransLowNet effective in challenging surveillance conditions.

GAT-Based Architecture

Graph Attention Network integration captures spatial relationships between multiple actors in the scene, substantially improving violence and anomaly event detection accuracy.

Edge Deployment

The modular pipeline is optimized for edge devices, enabling real-time inference without cloud dependency — critical for practical deployment in public transportation systems.

Multiclass Classification

Beyond binary anomaly detection, the framework classifies events across multiple violence categories, enabling actionable and context-aware security responses.
